# בונה האימונים שלי 🏋️

אפליקציית בניית אימונים (Web + Android + iOS) – אותו מראה ואותן יכולות כמו אפליקציית ה-Web המקורית:

- יצירה, עריכה ומחיקה של תוכניות אימון (סטים, מנוחה בין סטים, תרגילים לפי זמן או לפי חזרות)
- מצב אימון פעיל עם טיימר, צבע ירוק/אדום לעבודה/מנוחה, צלילים והשהיה
- **מסך מלא שנשאר** גם אחרי כיבוי והדלקת המסך, והמסך לא נכבה בזמן אימון
- **Android: האפליקציה מוצגת מעל מסך הנעילה** – אחרי כיבוי/הדלקת מסך רואים וממשיכים את האימון בלי לפתוח נעילה
- **הגנה מסגירה בטעות** – החלקת "חזרה" באמצע אימון לא עושה כלום, מחוץ לאימון היא ממזערת במקום לסגור, ואם האפליקציה בכל זאת נסגרה – האימון משוחזר בדיוק מאותה נקודה
- שמירה מקומית במכשיר **לשבוע בלבד** – אחרי שבוע תוכניות האימון נמחקות מהמכשיר (התאריך מוצג בקטן למעלה). משתמשים מחוברים לענן לא מושפעים
- **גיבוי בענן (Firebase, חינמי)** עם קוד אישי – יצירת קוד דורשת אישור שלך:
  1. המשתמש לוחץ "צור גיבוי ענן חדש" וממלא שם, פלאפון, מייל ובקשה
  2. בו-זמנית נשלחים למנהל מייל + טלגרם + וואטסאפ עם הפרטים וקישור לפאנל הניהול
  3. המנהל מדבר עם המשתמש, מאשר בפאנל (נפרד מהאפליקציה, רק למנהל) ושולח את הקוד בוואטסאפ / במייל
  4. המשתמש מזין את הקוד ומקבל גישה קבועה לסנכרון בענן מכל מכשיר

## מבנה
| קובץ / תיקייה | תוכן |
|---|---|
| `index.html`, `src/app.js` | האפליקציה (המבנה והלוגיקה המקוריים) |
| `src/cloud.js` | שמירה מקומית + ענן + בקשת קוד |
| `src/native.js` | מסך מלא ומניעת כיבוי מסך (דפדפן / Android / iOS) |
| `admin.html`, `src/admin.js` | פאנל הניהול – אישור בקשות, הנפקה וביטול קודים |
| `src/config.js` | **ההגדרות שצריך למלא** |
| `firestore.rules` | כללי האבטחה של הענן (+ בדיקות ב-`tests/`) |
| `android/`, `ios/` | הפרויקטים הנייטיביים |
